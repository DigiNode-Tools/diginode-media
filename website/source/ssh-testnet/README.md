# Testnet SSH screenshots

`../../guide/ssh-testnet/*.png` - the Raspberry Pi guide's step 5 screenshots (connecting with SSH), redrawn for the
`diginode-testnet` hostname. Shown on diginode.tools when the visitor ticks "I'm running a testnet node only".

They were made from the original `diginode` screenshots (2023, in the website's media library) by redrawing the
terminal text in the same font - Menlo for iTerm2 (`mac_testnet.py`), Cascadia Mono for Windows Terminal
(`win_testnet.py`, loaded from jsDelivr) - with `term.py` (headless Chrome). Long lines wrap and a full terminal
scrolls, like the real thing. The scripts expect the original screenshots next to them (download them from
diginode.tools/wp-content/uploads/2023/02/image-82..85.png and 2023/12/Screenshot-2023-12-08-192652-1.png,
-192822.png, -192905.png, Screenshot-2023-12-09-145732.png). Replace them with real screenshots when there is a
testnet DigiNode to take them from.
